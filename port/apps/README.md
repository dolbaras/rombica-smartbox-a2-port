# Приложения

Два вида приложений: наши собственные, встроенные в прошивку, и чужие проекты, доработанные под
приставку. Все подписываются одним ключом проекта.

```
apps/
  build_apps.sh          сборка встроенных приложений (без Gradle), вызывается из port/build.sh
  indicator/             ru.rombica.indicator: настройки индикатора, сведения о порте и changelog
  tvsettings_overlay/    оверлей TvSettings: пункт «Индикатор», экран порта, «Мышь и клавиатура»
  keys/rombica_apps.jks  ключ подписи (alias rombica, пароль rombica-a2); в репозиторий не входит,
                         build_apps.sh создаёт свой при первой сборке
  out/                   собранные встроенные приложения
  rustdesk/              RustDesk с аппаратным декодированием (отдельный APK, README.md)
```

## Доработанные чужие проекты

Каждый — в своей папке `apps/<проект>/`, по одной схеме:

- `README.md` — что изменено и зачем, что проверено, ограничения, как собрать и установить;
- `patches/` — наши изменения в виде `git format-patch` к закреплённой версии проекта
  (авторство Dolbaras), по одному патчу на законченное изменение;
- `build_<проект>.sh` — сборка с нуля: скачивает исходники нужной версии и инструменты,
  накладывает патчи, собирает и подписывает ключом проекта;
- `out/` — готовый APK (для пользователей — в [Releases](https://github.com/dolbaras/rombica-smartbox-a2-roms/releases) репозитория rombica-smartbox-a2-roms);
- по необходимости `install_on_box.sh`, `tools/`.

Исходники и тяжёлые инструменты (SDK, NDK, Flutter, vcpkg, промежуточные файлы) лежат вне
проекта, в `~/build/rombica-smartbox-a2/` (у RustDesk — `rustdesk/`, ~25 ГБ; в путях сборки не должно
быть пробелов): в проекте только то, что нужно, чтобы всё воспроизвести.

APK, подписанный нашим ключом, не ставится поверх официального: официальную версию нужно удалить
(данные приложения при этом сохраняют, см. `rustdesk/install_on_box.sh`). Обновления из
магазина или самого приложения вернули бы официальную версию без наших правок, поэтому
проверку обновлений в таких сборках отключаем.
