Rombica SmartBox A2 (S905L2, шасси VPN0123) — Android 9, порт v1.3, и Armbian на microSD
=====================================================================================

Скачать: https://github.com/dolbaras/rombica-smartbox-a2-roms/releases
Исходники и установщик для Linux: https://github.com/dolbaras/rombica-smartbox-a2-port

Файлы
  rombica_a2_android9_atv_v1.3.zip   Android 9 на базе SlimBOX 9.20 ATV (интерфейс Android TV)
  rombica_a2_android9_aosp_v1.3.zip  Android 9 на базе SlimBOX 9.20 AOSP (обычный лаунчер)
                                     В zip — образ .img в формате Amlogic USB Burning Tool.
                                     Ставить одну из двух прошивок.
  rombica_a2_bootloader_v1.3.img     только загрузчик (уже входит в обе прошивки)
  Armbian_…_server.img.xz            Armbian для microSD: только консоль (образ v1.2)
  Armbian_…_desktop.img.xz           Armbian для microSD: рабочий стол Xfce (образ v1.2)
  rustdesk-1.4.9-a2hw-armeabi-v7a.apk
                                     RustDesk с аппаратным декодированием (отдельно от прошивки)
  CHANGELOG.txt, CHANGELOG.ru.txt    что вошло в версию (на приставке: Настройки → Проект slimBOXtv →
                                     «Порт Rombica SmartBox A2»)
  SHA256SUMS                         контрольные суммы скачанных файлов и образов .img из zip:
                                       sha256sum -c --ignore-missing SHA256SUMS

ВНИМАНИЕ
  * Установка Android стирает всю память приставки (кроме заводских ключей: MAC и т.п. сохраняются).
  * Только для платы S905X_EMCP_V12 / шасси VPN0123 (Amlogic S905L2, 1 ГБ LPDDR3).
    Номер шасси — на наклейке снизу. На другой ревизии загрузчик может не запустить память.
  * Сделайте бэкап, если нужна возможность вернуться на заводскую прошивку (README, раздел
    «Откат на родную прошивку»).

Android
-------
Что понадобится
  * Кабель USB A–A (штекер–штекер), воткнутый в USB-порт приставки.
  * ПК с Linux (проверенный способ) или Windows с Amlogic USB Burning Tool (не проверялось).
  * Зубочистка: кнопка reset находится внутри гнезда AV.

Способ 1: Linux (проверен)
  1. Скачайте установщик и распакуйте прошивку (нужны python3, libusb-0.1 — пакет libusb-0.1-4):
        git clone https://github.com/dolbaras/rombica-smartbox-a2-port
        cd rombica-smartbox-a2-port/port
        unzip <папка загрузок>/rombica_a2_android9_atv_v1.3.zip
  2. Запустите:
        tools/install_firmware.sh rombica_a2_android9_atv_v1.3.img
     (или rombica_a2_android9_aosp_v1.3.img). Скрипт ждёт приставку до 5 минут. Если он
     пишет, что нет доступа к USB, добавьте правило udev для 1b8e:c003 или запустите через sudo.
  3. Выдерните питание приставки, зажмите reset в гнезде AV, вставьте питание и держите
     кнопку ещё 5–8 секунд.
     (Если на приставке нет рабочего загрузчика, она сама стоит в USB-режиме BootROM —
     скрипт это распознаёт и справляется без кнопки.)
  4. Дождитесь «INSTALL OK». Каждый раздел проверяется по sha1 самой приставкой.
     Первый запуск занимает несколько минут.

Способ 2: Windows, Amlogic USB Burning Tool (не проверялось)
  Образ .img из zip в стандартном формате aml_upgrade_package. Откройте его в USB Burning Tool
  (v2.x), включите «Erase flash», нажмите Start и подключите приставку, как в шаге 3.

Обновление с v1.0–v1.2 и переход ATV <-> AOSP
  Только полной установкой (стирает данные): у ATV и AOSP разные system, у v1.3 новые
  загрузчик, ядро, vendor, system и product.

После установки
  * adb: по сети, порт 5555 (adb connect <IP приставки>:5555), adb root работает.
    ВНИМАНИЕ: как и в SlimBOX, ADB открыт без подтверждения и с правами root — подключиться
    может любое устройство в той же сети. Не подключайте приставку к чужим и общественным сетям.
  * Настройки → Индикатор: роль для каждого цвета светодиода.
  * Настройки → Проект slimBOXtv → «Порт Rombica SmartBox A2»: версия и список изменений.
  * Пульт: кнопка «мышь» включает режим мыши (стрелки — курсор, OK — нажатие).
  * Настройки → Настройки slimBOXtv → «Мышь и клавиатура» → «Режим удалённого рабочего стола»
    (для RustDesk, RuDesktop; применяется сразу): правая кнопка мыши — правый клик, а Win,
    Alt+Tab, PrintScreen, Enter, Home уходят на удалённый компьютер (в клиенте режим клавиатуры
    «Карта»). Выключен (по умолчанию): правая кнопка — «Назад», как в SlimBOX.
  * Процессор работает до 1,512 ГГц (родная прошивка — до 1,2 ГГц); при перегреве (80 °C)
    частота снижается сама. Радиаторы на процессор и память не обязательны, но полезны.
  * Wi-Fi не ставьте вплотную к роутеру (от 1,5 м); при подключённом кабеле Ethernet Android
    к Wi-Fi автоматически не подключается.
  * Монитор ПК (с v1.3): родное разрешение выбирается само, уже в загрузчике (по EDID монитора);
    в Настройки → Экран → «Разрешение экрана» есть и другие режимы монитора.
  * Версия загрузчика видна в консоли UART: «U-Boot 2015.01-rombica-a2-v1.3». С подключённым
    UART в режим прошивки можно войти и без кнопки reset: остановить U-Boot пробелом и ввести
    «update 60000» (README, разделы 2 и 10).
  * Возврат на заводскую прошивку: README, раздел «Откат на родную прошивку VPLT».

RustDesk с аппаратным декодированием (apps/)
--------------------------------------------
  Официальный RustDesk для Android декодирует видео программно, на этой приставке — 2–3 кадра/с.
  Наша сборка 1.4.9 декодирует H.264/H.265 аппаратно и выводит кадр прямо на экран (30 кадров/с).
  Она подписана ключом порта, поэтому поверх официальной не ставится. Перенос с сохранением ID,
  пароля и адресной книги (adb, root есть в прошивке):
        port/apps/rustdesk/install_on_box.sh     (из репозитория rombica-smartbox-a2-port)
  Сборка сама не ищет обновления — не ставьте официальное обновление поверх, правки пропадут.
  В подключении оставьте кодек «Авто» (клиент попросит H.264). Подробно — port/apps/rustdesk/README.md.

Armbian на microSD (Android при этом остаётся на eMMC)
------------------------------------------------------
  1. Нужна карта от 8 ГБ (server) / 16 ГБ (desktop), лучше новая и известной марки:
     Armbian пишет на карту постоянно, дешёвые карты изнашиваются за недели.
  2. Распакуйте и запишите (в Linux, /dev/sdX — карта, проверьте lsblk!):
        xz -d Armbian_…_desktop.img.xz
        sudo port/sdcard/write_image.sh /dev/sdX Armbian_…_desktop.img   (rombica-smartbox-a2-port)
     Скрипт после записи сверяет образ чтением. Подойдёт и balenaEtcher / Rufus.
  3. Вставьте карту в выключенную приставку и включите. Загрузчик v1.2 и новее (прошивки
     Android v1.2, v1.3) показывает меню «Android | Armbian» и 10 секунд ждёт пульт:
        влево  — Android с eMMC;
        вправо, OK или ничего не нажимать — Armbian с карты.
     Без карты приставка грузит Android, как обычно.
  4. Первый запуск Armbian: на экране мастер — пароль root (сейчас 1234: пройдите мастер сразу,
     до этого по SSH можно войти с этим паролем), пользователь, часовой пояс.
     В desktop после мастера сразу открывается рабочий стол (автовход).
  Сеть: Ethernet работает сразу; Wi-Fi — nmtui (консоль) или значок сети (рабочий стол).
  НЕ запускайте armbian-install: он перезапишет eMMC и сотрёт Android.
  Подробно — port/armbian/README.md.
  Образы Armbian в этом выпуске — версии v1.2: образ v1.3 на приставке ещё не проверен.
